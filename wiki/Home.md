# 협업 개발 매뉴얼

이 Wiki는 GitHub Projects와 GitHub Issue를 이용해 작업을 관리하고, 개발부터 리뷰와 병합까지 일관된 방식으로 협업하기 위한 매뉴얼입니다.

## 문서

- [[GitHub Projects 도입]]  
  프로젝트 관리 도구의 필요성, GitHub Projects를 선택한 이유와 Issue 작성 및 관리 방법을 설명합니다.

- [[작업 순서]]  
  Issue 확인부터 사전 조율, 브랜치 생성, 개발과 테스트, Pull Request, 소스 리뷰, Merge 및 작업 종료까지의 순서를 설명합니다.

- [[Git 문제 해결]]  
  Git을 사용하다 자주 만나는 문제와 해결 방법을 설명합니다.
