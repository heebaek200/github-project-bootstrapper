# Daily Report — YYYY-MM-DD

오늘 하루의 작업 내용과 현재 상태를 공유합니다.

각 팀원은 업무 종료 전에 아래 댓글 양식을 복사하여 작성해 주세요. 코드 작성뿐 아니라 설계, 조사, 회의, 문서 작성과 리뷰도 작업으로 기록합니다.

내용을 정리할 때 LLM을 사용해도 좋습니다. 다만 작성자는 생성된 내용이 실제 수행한 작업과 일치하는지 확인하고, 관련 링크를 정확하게 첨부해 주세요.
